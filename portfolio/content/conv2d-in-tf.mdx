This article covers one of the core building blocks in deep learning for vision: the `Conv2D` operation in TensorFlow. I start with the intuition behind convolution, then move into the API shape and a practical Python example to show how the operation is actually used.

The goal was to make the jump from concept to implementation feel smaller for readers who are learning TensorFlow and convolutional neural networks at the same time.
