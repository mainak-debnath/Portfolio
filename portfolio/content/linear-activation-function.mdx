This article breaks down the linear activation function as a straight-line mapping of the weighted input. I cover the equation, a simple implementation, and the role activation functions play in helping neural networks learn beyond purely linear relationships.

One of the key takeaways is that linear activation is easy to compute and differentiate, but using only linear activations across layers restricts what the network can represent. That makes it a useful teaching concept, even when it is not the best choice for hidden layers.
